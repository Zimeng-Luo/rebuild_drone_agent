## 一、现场演示（90 秒，四步）

不在现场启动一次完整重建：2 分钟素材实测需要 466 秒，等不起。演示只做"看历史任务 → 展开摘要 → 按需加载模型 → 看证据"。上线前 10 分钟完成下列准备。

### 前置检查

```bash
# 1. 确认 GPU 空闲（只看不用）
nvidia-smi --query-gpu=index,memory.used,memory.total --format=csv

# 2. 启动服务，显式绑定单卡
cd /home/zimeng/rebuild_drone_agent
/home/zimeng/miniconda3/envs/rebuild_drone_agent/bin/python -m app.server \
    --host 127.0.0.1 --port 7860 --gpu-devices 1

# 3. 本机建立转发（另开终端）
ssh -p 21102 -L 17860:127.0.0.1:7860 zimeng@<host>
# 浏览器打开 http://127.0.0.1:17860

# 4. 确认存在已完成任务且产物齐全
curl -s http://127.0.0.1:7860/api/jobs | python -m json.tool | head -40
```

要点：至少一条 `status=completed` 的任务，其目录下有 `aligned.glb`；浏览器提前点开一次"查看"确认 WebGL 正常；缩放 125% 以上；关闭无关标签与通知。

- **服务连不上**：立刻切 PPT 第 16 页（界面）和第 13 页（点云），说"现场网络受限，界面以此为准"。不要反复刷新。
- **glb 加载慢**：说"这个模型 197 MB，现场带宽不稳，正好说明为什么要做按需加载"，超过 15 秒仍未出现就切回 PPT 第 13 页。不要在投影上开浏览器控制台。
- **被要求现场跑新任务**：说明 2 分钟 4K 素材实测 466 秒；可提交一个小图像目录样例并声明"只验证链路通不通，不代表质量"，同时展示排队位置与阶段进度作为过程演示。

## 五、复现口径

1. 点云坐标是模型推断的相对值，未接入外部控制点时不含绝对尺度。
2. 序列长度的实测范围是 2 分钟量级（81 帧、5 分块）；更长的序列会切更多块，显存不随之增长。
3. 回环搭配 IRLS 全局优化，本样例 3 对候选全部被接受，优化器是否生效可在 `alignment_evidence.json` 中查证。
4. `aligned.glb` 承载的是带颜色的点云，用于浏览器内快速查看与交互。
5. 性能数字来自单卡单任务实测，设备为 RTX 4090，显存 24 GB。
